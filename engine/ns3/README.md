# Backbone NetOps ns-3 Engine

The C++ simulation target is stored in this repository so its source remains versioned with the game.

ns-3 expects scratch programs inside its own source tree. Create a symbolic link from the ns-3 checkout to this file:

```bash
cd /path/to/ns-3
ln -s /path/to/Backbone-NetOps/engine/ns3/backbone-engine.cc scratch/backbone-engine.cc
```

Build only the Backbone NetOps target:

```bash
./ns3 build backbone-engine
```

The engine reads a topology scenario generated by the Python bridge. It creates ns-3 nodes, Ethernet links, L2 bridges, IPv4 interfaces, static routes, and ICMP echo traffic from the active game topology.
